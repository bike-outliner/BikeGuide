# Using Toolbar

The editor toolbar shows the path to your focused row, back and forward buttons, the filter field, and any command buttons you've added.

## Auto-Hide

Turn on **View > Auto-Hide Toolbar** (<kbd>Option-Command-/</kbd>) to hide the toolbar except while [filtering](outline-filtering.md).

## Toolbar Buttons

Add, remove, and reorder buttons in the [Interface Explorer](interface-explorer.md) under **Editor Toolbar Buttons**.
