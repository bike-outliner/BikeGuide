# Using Toolbar

Bike's editor toolbar runs across the top of the editor. It shows the path to your focused row, with back and forward buttons for retracing where you've been, alongside any command buttons you've added.

### Toolbar Buttons

The buttons on the toolbar come from Bike and from [extensions](using-extensions.md). To add a button, change its symbol, reorder the buttons, or remove one, use the [Interface Explorer](using-interface-explorer.md) and look under **Editor Toolbar Buttons**.

### Full Window Mode

When the window's title bar is hidden — for example in full window mode — the toolbar also hosts the **View** menu that normally lives in the title bar, so you still have it close at hand.
