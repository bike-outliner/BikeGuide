# Using Toolbar

Bike's editor toolbar runs across the top of the editor. It shows the path to your focused row, with back and forward buttons for retracing where you've been, alongside any command buttons you've added.

### Auto-Hide

By default the toolbar is always visible. But the toolbar is also one more strip of controls between you and your outline, and sometimes you'd rather just see your words. Turn on **View > Auto-Hide Toolbar** (<kbd>Option-Command-/</kbd>) for a cleaner, more focused window.

With auto-hide on the toolbar stays hidden until you start [filtering](using-outline-filtering.md). The moment a filter is active the toolbar slides back into view so you can see and edit your filter, then hides again once the filter is cleared. So you get the quiet window most of the time, and the toolbar shows up exactly when you need it.

### Toolbar Buttons

The toolbar is yours to arrange. The buttons on it come from Bike and from [extensions](using-extensions.md), so which buttons you want depends on which commands you reach for and which extensions you use. To add a button, change its symbol, reorder the buttons, or remove one, use the [Interface Explorer](using-interface-explorer.md) and look under **Editor Toolbar Buttons**.
