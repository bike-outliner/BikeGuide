# Extensions Explorer

Extensions add commands, keybindings, views, styles, and more. Sensitive capabilities need your permission. Find extensions on the [extension wiki](https://support.hogbaysoftware.com/t/bike-extensions-wiki/4810).

Open **Bike > Extensions Explorer** to install and manage extensions.

## Managing Extensions

* Uncheck an extension to disable it.
* Remove an extension to uninstall it.
