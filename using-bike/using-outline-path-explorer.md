# Outline Path Explorer

Open **Bike > Outline Path Explorer** to understand, compose, and debug Bike's outline search paths.

You don't need to use or understand this tool for most day-to-day Bike use. For more on outline paths, see [Using Outline Paths](using-outline-paths.md).
