# Printing Documents

Print an outline with File > Print…. The thing that makes printing in Bike a little different is simple: **it prints what you see.**

## Print What You See

Bike prints your outline exactly as you've shaped it on screen, so the easiest way to print just part of an outline is to set up that view first and then print:

* **Fold** rows away and their hidden children won't print. See [Outline Viewing](outline-viewing.md).
* **Focus** into a row and only that branch prints.
* **Filter** and only the matching rows print: the rows the filter tucks away show up as the same small "N Hidden" markers you see on screen, rather than printing in full. See [Outline Filtering](outline-filtering.md).

Combine these to print precisely the slice you want: focus a section, fold the parts you don't need, then print.

## Print Theme and Style

When you print, the macOS print dialog includes a couple of Bike-specific options:

* **Print Theme**: choose a [theme](using-themes.md) just for printing, independent of the light and dark themes you use while editing. This is where you'd set a clean, ink-friendly theme for paper while keeping something else on screen. The list offers light themes.
* **Print Style**: the [editor style](settings-window.md#appearance) used to lay the page out.

Your choices are remembered, so the next print uses the same theme and style.

The printed appearance comes entirely from that theme, so your theme's settings (its **fonts and colors**) are what land on the page. (Themes specify colors and fonts; see [Using Themes](using-themes.md).)

::: tip
The same print dialog can save a PDF instead of printing to paper. Use the **PDF** menu in the lower-left corner of the macOS print panel. It's a handy way to share a focused or filtered view of an outline.
:::
