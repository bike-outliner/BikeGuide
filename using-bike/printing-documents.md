# Printing Documents

Print with File > Print…. Bike **prints what you see**, so set up the view first:

* **Fold** rows away and their hidden children won't print. See [Outline Viewing](outline-viewing.md).
* **Focus** into a row and only that branch prints.
* **Filter** and only the matches print. See [Outline Filtering](outline-filtering.md).

## Print Theme and Style

The print dialog has two Bike options, both remembered:

* **Print Theme**: a light [theme](using-themes.md) used only for printing.
* **Print Style**: the [editor style](settings-window.md#appearance) used to lay out the page.

::: tip
Use the **PDF** menu in the print dialog to save a PDF instead.
:::
