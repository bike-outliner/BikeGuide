# Using Inspector

The inspector is an optional panel on the right side of the window where extensions show views, such as the [Calendar](using-calendar.md). With no extension views it shows "No Inspector Items".

## To show or hide the inspector

* View > Show Inspector / Hide Inspector

## Inspector Tabs

Each item gets a tab icon at the top of the inspector. Hover to see its label.

To build your own inspector views, see the [DOM Context Tutorial](https://github.com/bike-outliner/extension-kit/blob/main/docs/dom-context-tutorial.md).
