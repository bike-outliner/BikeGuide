# Using Themes

Themes set Bike's colors, materials, and typography. You can pick separate themes for light and dark mode. Find more on the [extension wiki](https://support.hogbaysoftware.com/t/bike-extensions-wiki/4810).

**To choose a theme:**

1. Open Bike > Settings > Appearance
2. There choose your preferred theme for light mode and dark mode.

**To install a theme:**

1. Choose Bike > Settings > Appearance
2. Click the "Open Themes Folder…" button
3. Drag or modify any top level `.bktheme` file in that folder
4. The theme appears in the Appearance popups. If it doesn't, check Bike > Logs Explorer for errors.
