# Using Explorers

Bike includes several explorer windows for inspecting and customizing different aspects of the application. Open them from the **Bike** menu.

- [Commands Explorer](using-commands.md) — View and customize commands and keybindings
- [Extensions Explorer](using-extensions.md) — Manage installed extensions
- [Interface Explorer](using-interface.md) — Inspect the outline interface
- [Logs Explorer](using-logs.md) — View application logs
- [Outline Path Explorer](using-outline-path-explorer.md) — Compose and debug outline paths
