# Using Explorers

Bike includes several explorer windows for inspecting and customizing different aspects of the application. Open them from the **Bike** menu.

- [Commands Explorer](commands-explorer.md) — View and customize commands and keybindings
- [Extensions Explorer](extensions-explorer.md) — Manage installed extensions
- [Interface Explorer](interface-explorer.md) — Inspect the outline interface
- [Logs Explorer](logs-explorer.md) — View application logs
- [Outline Path Explorer](outline-path-explorer.md) — Compose and debug outline paths
