# Creating Themes

Themes customize Bike's colors, materials, and typography. A theme is a single `.bktheme` file that you can write yourself, adapt from an existing theme, and share with others. For choosing and installing finished themes, see [Using Themes](../using-bike/using-themes.md).

The easiest way to start is to copy a theme you like and change one thing at a time. The full reference is in the extension-kit docs:

* [Bike Extension Kit: Creating Themes](https://github.com/bike-outliner/extension-kit/blob/main/docs/creating-themes.md)
