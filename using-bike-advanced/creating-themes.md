# Creating Themes

Themes customize Bike's colors (with font support planned). A theme is a single `.bktheme` file that you can write yourself, adapt from an existing theme, and share with others. For choosing and installing finished themes, see [Using Themes](../using-bike/using-themes.md).

### Getting started

The best way to learn the format is from a working example. The extension kit includes a documented example theme and the full schema:

* [Theme API — example and schema](https://github.com/bike-outliner/extension-kit/tree/main/api/theme)

Bike's bundled themes are also good starting points — copy one and change it to taste.

### Editing a theme

1. Open Bike > Settings > Appearance and click "Open Themes Folder…".
2. Add or edit a top-level `.bktheme` file in that folder.
3. New and changed themes appear right away in the Appearance menus.

If a theme doesn't appear, it likely has a syntax error. Open [Bike > Logs Explorer](../using-bike/using-logs.md) to see what went wrong.
