# Creating Extensions

Extensions add commands, keybindings, views, styles, and more, using the same machinery as Bike's built-in features. AI assistants are good at writing them.

The SDK, examples, and reference live in the extension-kit:

- [Bike Extension Kit](https://github.com/bike-outliner/extension-kit)
