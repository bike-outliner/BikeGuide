# Creating Extensions

Extend and customize Bike with extensions. They introduce new commands, keybindings, views, styles, and more. Sensitive features are safeguarded by a permission system.

Use the [Bike Extension Kit](https://github.com/bike-outliner/extension-kit) to create extensions. The extension kit includes:

- API documentation and type definitions
- Tools for creating, building, installing, and testing extensions
- Tools to package, release, and submit extensions to Bike's extension registry

See the extension kit's [documentation](https://github.com/bike-outliner/extension-kit/tree/main/docs) for tutorials and guides:

- [Creating Extensions](https://github.com/bike-outliner/extension-kit/blob/main/docs/creating-extensions.md) — overview and getting started
- [App Context Tutorial](https://github.com/bike-outliner/extension-kit/blob/main/docs/app-context-tutorial.md) — commands, keybindings, and outline APIs
- [DOM Context Tutorial](https://github.com/bike-outliner/extension-kit/blob/main/docs/dom-context-tutorial.md) — custom UI with HTML and DOM
- [Style Context Tutorial](https://github.com/bike-outliner/extension-kit/blob/main/docs/style-context-tutorial.md) — custom editor stylesheets
- [Testing Extensions](https://github.com/bike-outliner/extension-kit/blob/main/docs/testing-extensions.md) — automated testing
- [Sharing Extensions](https://github.com/bike-outliner/extension-kit/blob/main/docs/sharing-extensions.md) — packaging and distribution
